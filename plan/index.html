전략

페이지가 무엇을, 누구에게, 어떤 논리로 설득하는가

1-1. 기획 개요

페이지 목적AI 진입장벽을 느끼는 일반 사용자에게 "그리도스는 배우지 않아도 되는 AI"임을 설득하고, 단일 전환 액션(CTA)으로 유도
타겟AI를 어려워하거나, AI를 쓰고 있어도 채팅(검색·번역) 수준에 머무는 일반 사용자 — 자영업자·프리랜서·사무직·학생
포지셔닝"배워서 쓰는 AI 도구"가 아니라 "말만 하면 함께 일하는 AI 팀원" — 학습 비용 0을 전면에
핵심 차별점① 대화가 흘러가지 않고 폴더 구조로 적층되어 자산이 됨 ② 맥락을 기억해 쓸수록 나를 아는 AI ③ 자동화가 대화 한마디로 만들어짐
현행 대비grid-os.ai 현행은 B2B(도입 문의) 중심 · 마케팅 대행사 에디션 우선 — 본 기획은 일반 사용자 버전으로 언어·사례·CTA 전면 재설계
전환 목표확정 필요: 다운로드 / 사전신청(이메일) / 문의 중 택 1 — 이하 CTA 문구는 "그리도스 시작하기"로 가안

S0

Summary — 히어로

HOOK · 주목

3초 안에 "이건 나를 위한 AI"를 각인. 기능 나열 대신 '배울 필요 없음'을 선언.

전환 논리 — 타겟은 "AI = 배워야 하는 것"이라는 전제를 갖고 진입한다. 그 전제를 첫 문장에서 뒤집어야 스크롤이 시작된다.

WIREFRAME · HERO

AI, 배우지 말고
그냥 시키세요

설치하고 말만 하면 — 정리·문서·반복 업무를 AI 팀원이 대신하는 나의 업무 OS, 그리도스

제품 실화면: 대화 → 결과물 생성 장면 (15초 루프 영상)
그리도스 시작하기
설치형강의 불필요내 데이터는 내 것

컴포넌트

  • 메인 헤드라인 + 서브카피
  • 제품 실화면 루프 영상 1개 (대화 → 결과, 15초 이내·무음 자동재생)
  • 메인 CTA 버튼 1개 — 보조 버튼 없음 (선택지 최소화)
  • 신뢰 칩 3개 (Foundation 요소)

내용 (카피)

  • A안: "AI, 배우지 말고 그냥 시키세요"
  • B안: "당신은 말만 하세요. 일은 그리도스가 합니다"
  • C안: "프롬프트를 몰라도, 폴더를 몰라도"
  • 서브: "설치하고 말만 하면 — 정리·문서·반복 업무를 AI 팀원이 대신하는 나의 업무 OS"

비주얼 · 모션

  • 영상은 반드시 실화면 녹화 — 합성 목업은 신뢰 하락. 타이핑 → 결과물 생성까지 끊김 없이.
  • 헤드라인 페이드업 → 영상 재생 → CTA 등장 순의 로드 시퀀스 (1.5초 이내 완료).

기획 노트

  • A안 권장 — 명령형이 타겟의 수동성("나는 못해")을 정면으로 해제.
  • CTA 목적지 확정 필요 → 버튼 문구 확정 (1-1 개요 참조).
S1

고민+해결 — Before → After 시연

SHOW · 증명

추상 설명 전에 '장면'부터. 수작업이 한마디로 끝나는 대비를 3장면으로.

전환 논리 — 히어로의 선언은 아직 '주장'이다. 설득 문장을 늘리는 대신 즉시 증거(장면)를 제시해 의심 구간을 최단으로 끊는다.

WIREFRAME · BEFORE/AFTER ×3

매일 하던 그 일,
이제 한마디면 됩니다

BEFORE엑셀 열고 복사·붙여넣기 2시간, 수식 깨져서 다시…
AFTER"이번 달 자료 정리해서 표로 만들어줘" → 리포트 완성
BEFORE"그때 그 얘기 어디에 적었더라…" 폴더 뒤지기 30분
AFTER"지난번에 뭐라고 결정했지?" → 히스토리에서 바로 답변
BEFORE매번 같은 세팅을 처음부터 반복 (광고·문서·정산…)
AFTER"저번처럼 세팅해줘" → 이전 방식 그대로 자동 실행

컴포넌트

  • 섹션 헤드라인
  • Before/After 카드 3개
  • 각 카드 실화면 캡처 1컷 (After 쪽)

내용 (3개 시나리오)

  • ① 엑셀 수작업 → 리포트 자동화 (P1·P2 공통 통점)
  • ② 히스토리 질문 → 이전 기록 기반 즉답 (P2·P3)
  • ③ 반복 세팅 → "저번처럼" 자동 실행 (광고세팅은 예시 중 하나로)

비주얼 · 모션

  • Before는 회색·저채도, After는 본색 — 감정의 명암을 색으로.
  • 스크롤 진입 시 Before 먼저 표시 → 0.4초 후 After 리빌. 모바일 세로 스택.

기획 노트

  • '광고세팅'은 일반 타겟에게 낯선 어휘 — "반복 세팅"으로 일반화하고 괄호 예시 처리.
  • 시나리오는 페르소나 3명과 1:1 대응하도록 설계됨 (내용 칸 참조).
S2

일반 소비자의 고민 — 공감

EMPATHY · 공감

"이거 완전 내 얘기"를 만드는 공감 섹션. 타겟이 스스로를 인식하게 한다.

전환 논리 — 시연(S1)을 본 직후 "그래도 나는 못 쓸 것 같은데"라는 방어가 올라온다. 그 방어의 언어를 먼저 말해주고, 책임을 사용자에서 '방식'으로 옮긴다.

WIREFRAME · 공감 말풍선

혹시, 이런 적 있으신가요?

"AI 강의를 3개나 들었는데, 막상 켜면 뭘 해야 할지 모르겠어요"
"GPT 유료 결제했는데… 결국 검색이랑 번역만 시켜요"
"자동화? 폴더? 터미널? 듣기만 해도 머리가 아파요"
"남들은 AI로 일 줄인다는데, 내 일엔 적용이 안 돼요"

문제는 당신이 아니라, AI를 '배워야 쓰는 도구'로 만든 방식입니다

컴포넌트

  • 섹션 헤드라인 (질문형)

  • 전환 카피 1줄 — 섹션의 실질적 결론

내용 (카피)

  • 말풍선 4개: 강의 무력감 / 채팅 한계 / 용어 공포 / 적용 실패 — 페르소나 P1·P2·P3의 실제 언어
  • 전환: "문제는 당신이 아니라, AI를 '배워야 쓰는 도구'로 만든 방식입니다"

비주얼 · 모션

  • 말풍선은 채팅 UI 톤 — "채팅만 하는 유저"가 자기 화면처럼 느끼게.
  • 스크롤 시 말풍선 순차 등장(0.15초 간격) → 전환 카피는 여백을 두고 단독 등장.

기획 노트

  • 전환 카피가 이 섹션의 전부 — 자책 해소가 되어야 S4의 해법이 '내 것'으로 들린다.
  • 말풍선 문구는 추후 실제 VOC·커뮤니티 질문에서 발췌해 교체하면 신뢰도 상승.
S3

URGENCY · 위기감

"남 얘기가 아니네"를 만드는 FOMO 섹션. 공감(S2)으로 풀린 자책을 '지금 시작할 이유'로 전환한다.

전환 논리 — S2가 "당신 잘못이 아니다"로 마음을 열었다면, S3는 "그래도 미루면 격차는 벌어진다"는 외부 사실을 보여 행동 동기를 만든다. 위기감은 통계와 출처로 담백하게 — 과장하면 바로 뒤 S4의 해소가 가볍게 들린다.

S4

해결방안 — 설치 → 첫 대화 → 실행

RELIEF · 해소

"강의 없이 3단계면 끝"이라는 낮은 진입장벽을 프로세스로 증명.

전환 논리 — 공감으로 열린 마음에 '구체적이고 짧은 절차'를 제시. 단계가 3개를 넘거나 용어가 어려우면 S2에서 만든 신뢰가 즉시 붕괴된다.

WIREFRAME · 3-STEP

어려운 강의는 필요 없습니다

STEP 1 · 설치

STEP 2 · 첫 대화

AI가 먼저 물어봅니다 — "어떤 일을 하세요?" 대답만 하면 내 업무에 맞게 준비 완료.

STEP 3 · 그냥 말하기

"이것 좀 정리해줘" — 첫날부터 바로 일이 됩니다.

첫 대화(온보딩) 실화면 캡처

컴포넌트

  • 섹션 헤드라인
  • 스텝 카드 3개 (번호·제목·설명)
  • 첫 대화 실화면 1컷

내용 (카피)

  • "어려운 강의는 필요 없습니다. 설치하고, 대답하고, 말하세요."
  • STEP 2 핵심: "AI가 먼저 물어봅니다" — 사용자가 배우는 게 아니라 AI가 사용자를 배운다는 관점 전환.

비주얼 · 모션

  • 스텝 카드는 세로 진행 + 연결선 — 순서가 정보이므로 번호 마커 사용 (이 페이지에서 번호는 S4에만).
  • STEP 2 캡처에는 AI의 질문 말풍선이 보이도록 — "AI가 먼저 묻는다"의 시각 증거.

기획 노트

  • '온보딩'이라는 단어 자체가 타겟에게 장벽 — 화면 표기는 "첫 대화"로 통일.
S5

전환 논리 — 여기까지 온 독자는 "그럴듯한데, 원리가 뭐지?"라는 합리화 근거를 찾는다. 원리를 이해한 사용자는 이탈률이 급감한다 — 단, 설명은 은유로.

  • 이 섹션이 일반 채팅 AI와의 결정적 차별점 — S9 비교표의 논리 근거가 여기서 심어진다.
  • "폴더" 강조는 양날 — 타겟이 폴더를 어려워하므로 "당신이 몰라도 알아서" 프레임 필수. S2의 "폴더? 터미널?" 고민과 직접 호응.

  • 3행: 기억(리셋 vs 축적) / 결과물(대답 vs 저장) / 반복(매번 vs 자동)
  • 마무리: "채팅은 대답하고 끝나지만, 팀원은 일을 끝냅니다" — Pillar 1·2를 한 문장으로 회수

비주얼 · 모션

  • 좌(회색·저채도) vs 우(본색) — S1과 동일한 색 문법으로 페이지 전체의 시각 언어 통일.

기획 노트

  • 타사 브랜드명 직접 표기 금지 — "일반 AI 채팅"으로 통칭 (비교광고 리스크 회피).
  • 비교 항목은 검증 가능한 사실 위주로 — 성능·품질 우열 표현("더 똑똑함" 등)은 배제.
S10

후기

PROOF · 사회적 증거

"나 같은 사람도 쓰는구나"의 사회적 증거. 직군·연령을 페르소나에 맞춰 배치.

전환 논리 — 논리 설득(S9)이 끝난 자리에 감정 확신을 얹는다. 후기 인물 = 페르소나 — 독자가 자기와 같은 사람을 발견하게 하는 캐스팅이 핵심.
